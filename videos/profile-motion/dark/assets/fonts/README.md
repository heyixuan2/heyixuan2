# Bundled font provenance

`jetbrains-mono-regular.woff2` and `jetbrains-mono-extrabold.woff2` are unmodified
JetBrains Mono webfont files. They were copied from the local HyperFrames font cache
on 2026-09-19 after license verification against the upstream project.

- Copyright: 2020 The JetBrains Mono Project Authors
- License: SIL Open Font License 1.1
- Upstream license: https://github.com/JetBrains/JetBrainsMono/blob/master/OFL.txt

The SIL OFL permits embedding and redistribution when the copyright notice and license
are retained. Do not rename or modify these bundled files without reviewing the OFL's
Reserved Font Name requirements.

`inter-black.woff2` is the unmodified Latin, normal, 900-weight file from
`@fontsource/inter` 5.3.0. The package reports `OFL-1.1`; its full license is retained
as `LICENSE-Inter-OFL-1.1.txt`. This display face replaces JetBrains Mono only for the
three large step lines, preserving the original hero's compact Swiss/grotesk character.
