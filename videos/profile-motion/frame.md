# Profile Motion — Frame Direction

## Purpose

A 1600 × 360 README strip that reads as a complete editorial statement before it moves. It communicates practical MVP delivery and enterprise-level engineering without claiming a job title or role: clarify an idea, build the MVP, learn and iterate.

## First frame / final frame

Both frames show the full lockup. Place the tracked mono eyebrow `FROM IDEA TO MVP` in the upper band; beneath it, use three generous horizontal columns with two large lines each: `Clarify / the idea.`, `Build / the MVP.`, and `Learn. / Iterate.` Retain `Fast to first value. Built for real use.` as small mono copy at lower left. The long positioning headline is already native README text and is deliberately omitted from this 360px strip. Thin structural rules give the composition an architectural spine. The final frame is the all-three-step overview, held still for 1.35 seconds.

## Visual system

Use the reference assets only as art direction, not as moving media: warm paper/charcoal field, oversized dense type, monospaced utility labels, hard editorial alignment, thin structural rules, and orange used sparingly as a functional signal. The light edition is `#f5f2ea` background / `#171717` ink / `#ed5c24` accent. The dark edition is `#151719` background / `#f3efe6` ink / `#ff783e` accent. The approved typography uses bundled Inter Black 900 for display and JetBrains Mono for utility copy.

## Motion

At 30fps across exactly 4.8s (144 frames), all text is already present at frame 0. The only motion is three gentle left-to-right horizontal reveals: `idea.` from 0.25–0.85s, `MVP.` from 1.45–2.05s, and `Iterate.` from 2.65–3.25s. Each reveal uses an orange duplicate within a horizontal mask and a matching 2px rule; the original ink text remains visible beneath it. At 3.45s the three accents resolve as one quiet overview, then the frame holds to the end. Use smooth, non-elastic easing; no zoom, bounce, blink, flash, glitch, cursor, or grain animation.

## Delivery

Export directly to silent GIF after preview approval: 15 fps, 72 frames, 4.8 seconds, looping with a final hold. Supply final-frame PNGs for reduced-motion visitors and explicit static links. Keep the strip legible at 800px wide: preserve at least 64px side padding, never crop text, and use no detail that depends on animation to be understood. Paint the opaque background on the inner scene because alpha-capable exports clear composition-root backgrounds.
