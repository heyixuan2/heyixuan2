# Profile UI

Self-contained animated SVG links and disclosure labels for the profile README.
Warm paper, charcoal, orange linework, stable heavy typography. The accepted
photographic hero, project images and footer are not generated by this tool.

## Build and Test

```sh
node tools/profile-ui/generate.mjs
node --test tools/profile-ui/generate.test.mjs
node tools/profile-ui/preview.mjs
```

The generator has no dependencies or network calls. It writes 22 desktop SVGs
and six compact project/notes variants to `assets/ui/`. Each file contains its
own CSS animation and respects `prefers-reduced-motion`. The README selects
dark/light and compact sources with `picture`; there are no visible theme links.

The preview uses the authenticated GitHub CLI Markdown renderer once at startup,
then serves only this README and its public assets on `127.0.0.1:4324`. The
theme, narrow-width and reduced-motion switches belong only to the preview.
No hover effects or client scripts are required by the published README.

## Interaction and Accessibility

- Labels do not move, disappear or retype. Icons, arrows and orange rules move.
- All links remain ordinary keyboard-accessible anchors with meaningful alt text.
- Disclosure images remain inside native `summary` elements; GitHub owns their
  expansion state and keyboard behavior.
- Small-screen project titles use larger, multiline lettering. Notes use a
  shorter visual label with the full accessible name preserved.
- No third-party counters, fonts, image services, JavaScript or tracking URLs.
- Animation is decorative, never a fake click, status, progress or loading state.

The current Bambu Studio AI README's self-contained animated SVGs were the
implementation reference; these controls are newly authored for this profile's
established visual identity.
